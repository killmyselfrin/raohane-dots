# Raohane Nocturne — design showcase

These **original illustrative SVG concept images** accompany the root [README](../../README.md):

- [Nocturne desktop](nocturne-desktop.svg) — floating Bar, Context Island, Launcher, Dock and Control Center.
- [Settings](nocturne-settings.svg) — a shared dark theme system, navigation and appearance controls.

**Important:** these are authored presentation illustrations, not screenshots from the running Quickshell application. They are intended to communicate visual direction, not prove that every shown button works or every proposed feature has shipped.

For release documentation, add real screenshots separately **after** checking the installed shell in an actual Hyprland session. Use factual image captions, record the build/revision and test resolution, and avoid presenting generated concepts as runtime evidence. See [release validation](../../docs/RELEASE-VALIDATION.md).

The SVG files are self-contained (no remote image or font dependencies) and are designed to remain crisp on high-density displays.
