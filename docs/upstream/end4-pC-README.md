## Installation note from the upstream snapshot

The upstream fork manages its own configuration folder independently and requires
`illogical-impulse` to already be installed and running. Raohane does **not** use
that installation model: the migration branch vendors the system/dependency source
and provides its own standalone installer and namespace.

For the complete historical upstream README, consult the pinned upstream repository
at commit `369554b62de8d659875de828c779b83b28ae9ada`.
